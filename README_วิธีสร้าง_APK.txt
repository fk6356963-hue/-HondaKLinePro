===================================================================
โปรเจกต์: Honda K-Line Pro (เมนูภาษาไทย) สำหรับช่างทีม
===================================================================

ภายในไฟล์ .ZIP นี้บรรจุโครงสร้างโปรเจกต์ Android Studio ครบชุด พร้อม:
1. ซอร์สโค้ดเต็มรูปแบบ (แดชบอร์ด RPM ขนาดใหญ่, AFR, ECT, แบตเตอรี่, พารามิเตอร์ทั้งหมด, เช็ค/ลบโค้ด, ตารางแมพ & แฟลช .BIN)
2. ไฟล์ตัวอย่าง Honda_Sample_ROM_64KB.bin สำหรับทดลองเปิดตารางแมพในแอปได้ทันที
3. สคริปต์ .github/workflows/build_apk.yml สำหรับสั่งสร้างไฟล์ .APK อัตโนมัติบนเว็บ GitHub (กรณีไม่มีคอมที่ลง Android Studio)

-------------------------------------------------------------------
วิธีที่ 1: เปิดด้วยโปรแกรม Android Studio ในคอมพิวเตอร์
-------------------------------------------------------------------
1. แตกไฟล์ (Extract) โฟลเดอร์ HondaKLinePro ออกมาจากไฟล์ .zip นี้
2. เปิดโปรแกรม Android Studio -> กด Open -> เลือกโฟลเดอร์ HondaKLinePro
3. รอโปรแกรม Sync Gradle สักครู่
4. ไปที่เมนูด้านบน Build -> Build Bundle(s) / APK(s) -> Build APK(s)
5. นำไฟล์ app-debug.apk ที่ได้ไปติดตั้งลงมือถือ Android ได้ทันที

-------------------------------------------------------------------
วิธีที่ 2: สร้างไฟล์ .APK ฟรีบนเว็บ GitHub (ไม่ต้องลงโปรแกรมในคอม/ทำผ่านมือถือได้)
-------------------------------------------------------------------
1. สมัครและเข้าเว็บ GitHub.com แล้วสร้าง Repository ใหม่ (ตั้งชื่อเช่น HondaKLinePro)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ HondaKLinePro ขึ้นไปยัง Repository
3. กดไปที่แถบเมนู "Actions" บนเว็บ GitHub -> เลือก "Build Honda K-Line Pro APK" -> กด "Run workflow"
4. รอประมาณ 2-3 นาที เมื่อขึ้นเครื่องหมายถูกสีเขียว ให้กดเข้าไปดาวน์โหลดไฟล์ "Honda-KLine-Pro-APK" จะได้ไฟล์ app-debug.apk พร้อมติดตั้งลงมือถือทันทีครับ!
